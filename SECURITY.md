# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Use
**[Security › Report a vulnerability](https://github.com/issacbrizuela1/PUB-P-APP-ROUTEHOUND/security/advisories/new)**:
the report stays private between you and the maintainer.

Include the Routehound version, your operating system and the steps to reproduce it. Do not
include real tokens or private data; sample values are enough.

Routehound is maintained by one person, so replies are best effort. Fixes ship in the next
release, and only the latest version receives them.

---

## Reportar una vulnerabilidad

**No** abras un issue público para un problema de seguridad. Usa
**[Security › Report a vulnerability](https://github.com/issacbrizuela1/PUB-P-APP-ROUTEHOUND/security/advisories/new)**:
el reporte queda privado entre tú y el responsable.

Incluye la versión de Routehound, tu sistema operativo y los pasos para reproducirlo. No incluyas
tokens reales ni datos privados; basta con valores de ejemplo.

Routehound lo mantiene una sola persona: las respuestas son de mejor esfuerzo. Las correcciones
salen en la siguiente versión y solo la última versión las recibe.
